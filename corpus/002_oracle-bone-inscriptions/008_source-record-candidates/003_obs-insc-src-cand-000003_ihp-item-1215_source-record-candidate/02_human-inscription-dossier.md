# Human inscription source dossier / 人类卜辞来源档案

## Source-reported wording / 来源文字

The museum page displays the short Chinese string `帚（婦）井示。韋。`.
The characters are copied as displayed by the source page. This dossier does
not assign each string to a visible stroke or fragment.

The English page describes the inscriptions on both sides of the fanned
carapaces as Lady Jing inspecting the carapaces, with Wei as recipient. This
is source-reported museum wording, not a project translation or settled
reading.

博物馆页面显示短字符串 `帚（婦）井示。韋。`。本档案按来源页面记录，不把
字符串逐字分配到可见刻痕或残片。

英文页面把扇形龟甲两面的卜辞说明为妇井视察龟甲、韦为受事者。这里仅记
录馆方说法，不把它提升为项目翻译或定论。
