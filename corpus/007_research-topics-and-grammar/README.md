# Research Topics And Grammar / 研究主题与语法

English:
This corpus area stores preprocessing materials for topic labels, controlled-vocabulary candidates, and later grammar-position review. It does not contain confirmed grammar analysis, accepted inscription-topic assignments, readings, transcriptions, or decipherment conclusions.

简体中文：
本语料区保存主题标签、受控词表候选以及后续语法位置复核所需的预处理资料。这里不保存已确认的语法分析、已接受的卜辞主题归属、读法、释文或破译结论。

## Current Materials / 当前资料

- `000_topic-registers/001_cambridge-hopkins-topic-candidate-index.csv`: index of Cambridge/Hopkins classified-table topic candidates.
- `000_topic-registers/002_cambridge-hopkins-topic-crosswalk-link-staging.csv`: routed topic-to-inscription-crosswalk staging rows.
- `000_topic-registers/003_cambridge-hopkins-unrouted-crosswalk-staging.csv`: unclassified crosswalk rows that could not be routed to a topic candidate.
- `001_topic-candidates/`: object-local topic candidate directories. Each directory keeps human-readable review material and AI-readable packet/index files together.

## Object-Local Rule / 对象内资料规则

English:
Each topic candidate directory contains its own README, human review sheet, source index, period-count index, crosswalk route index, and JSON packet. Do not create a parallel human-readable directory for these materials.

简体中文：
每个主题候选目录都在对象内部放置 README、人工复核表、来源索引、分期计数索引、crosswalk 路由索引和 JSON packet。不要为这些资料再创建并行的人类可读目录。

## Boundary / 边界

English:
All records in this area are preprocessing candidates or review routes only. They are evidence-routing infrastructure, not formal scholarship.

简体中文：
本区所有记录都只是预处理候选或复核路线。它们是证据路由基础设施，不是正式学术结论。
