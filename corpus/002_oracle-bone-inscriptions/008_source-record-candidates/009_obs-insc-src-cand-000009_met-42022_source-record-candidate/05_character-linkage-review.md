# Character and component linkage review / 单字与构件关联复核

## Current state / 当前状态

No character, component, variant, near-form, modern-character, bronze-script,
seal-script, or evolution edge is assigned to this object. The Met API gives
no glyph IDs or text labels, and the images have not been segmented.

本对象没有分配单字、构件、异体、近形、今字、金文、小篆或演化图边。大都会
API 没有提供字形 ID 或文字标签，图像也没有分段。

The red accession marking visible in one view is collection metadata, not a
character occurrence. Surface pores and incisions are not silently converted
into character boundaries.

一张图中可见的红色馆藏标记是馆藏 metadata，不是单字出现。骨面孔隙和刻痕
不会被静默转换成单字边界。

## Required evidence before linkage / 建立关联前的必要证据

- stable object and plate identity;
- a rights-permitted image or rubbing with orientation;
- line-addressable transcription or OCR;
- coordinate-bound sign segmentation;
- independent near-form and component comparisons;
- positive and negative evidence for every proposed link.

- 稳定的对象和图版身份；
- 带方向且权利明确的图像或拓片；
- 可定位的释文或 OCR；
- 与坐标绑定的字形分区；
- 独立的近形和构件比较；
- 每条候选关联的正反证据。

The absence of a linkage row is a preprocessing status, not evidence of a
reading or scholarly agreement.

没有关联行只是预处理状态，不是释读或学术共识的证据。
