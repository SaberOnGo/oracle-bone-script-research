# 质量门禁与度量 / Quality Gates And Metrics

- 状态 / Status: `proposed_gates_pending_implementation`
- 目的 / Purpose: 把"人类可读为主、不堆模板"变成脚本能检查的规则

用户 2026-08 的要求是"写成脚本，门禁，防止后面又走偏了"。现有校验
只检查结构。本文件定义内容门禁；实现放在
`tools/validation/check_content_gates.py`，并配测试。

Existing validators check structure only. This file defines content gates to
be implemented in `tools/validation/check_content_gates.py` with tests.

## 1. 行级分类 / Line Classification

对 `corpus/`、`research/`、`doc/public/user_research/` 下每个 Markdown
的非空行分三类：

| 类别 | 判定 | 例 |
| --- | --- | --- |
| 模板行 | 同一行文本在 ≥ 2% 的被检文件中出现 | 边界声明、固定待查句 |
| 字段行 | 形如 `- 名称: 值` 的 ID / 状态行 | `- project id: ...` |
| 实质行 | 其余（含来源标记的叙述、表格数据、观察、例句） | 释读史条目 |

`实质比 = 实质行 / 非空行`。

## 2. 门禁 / Gates

| 编号 | 规则 | 阈值 | 级别 |
| --- | --- | --- | --- |
| G1 | 单个对象档案实质比 | ≥ 50%（试点目录 ≥ 70%） | 阻断 |
| G2 | 对象目录内人读 Markdown 数 | = 1（`README.md`） | 阻断 |
| G3 | 档案内"不是释读结论"类声明 | ≤ 1 行 | 阻断 |
| G4 | 同一 ID / 状态字段在同一文件重复 | ≤ 1 次 | 警告 |
| G5 | 固定待查句（"待查：需核对"、"only route record" 等） | 0 | 阻断 |
| G6 | 路径、URL、ID 中间换行 | 0 | 阻断 |
| G7 | 单次提交新增对象目录数 | ≤ 10 | 阻断 |
| G8 | 单次提交新增非语料文件数 | ≤ 200 | 警告 |
| G9 | 新增 `*_scaffold*` / `*_queue*` / `*_handoff*` / `*_route_pack*` 文件 | 0 | 阻断 |
| G10 | 对象目录存在但不满足"按需建目录"条件 | 0（迁移期白名单） | 警告 |
| G11 | `record.json` 字段与 `README.md` 互检 | 全部对应 | 阻断 |
| G12 | 全量测试运行时间 | ≤ 5 分钟 | 警告 |
| G13 | 正文中出现扩展区 Unicode 字符而无图或码位说明 | 0 | 警告 |

迁移期（第 1 至 3 步完成前）G1、G10 对现有目录只报告不阻断；对新建
目录立即阻断。

## 3. 仓库级度量 / Repository Metrics

每次全量校验输出一份 `tmp/content-metrics.json` 和一段人读摘要，含：

- 跟踪文件总数；人读 Markdown / 机读文件 / 图片的数量与比例；
- 全仓库实质比（抽样 3,000 个文件估计）；
- 满足最低章节要求的单字档案数（已释 / 未释分开）；
- 有释读史的已释字档案数；有 ≥ 3 条例句的已释字档案数；
- 卜辞释文记录数（有全文 + 著录号 + 来源）；
- 有 `source_ref` 的学术关系边数；
- 研究案件数与状态分布；盲测轮次与最近命中率；
- 全量测试时长。

这些数字进入 README 的"当前状态"一节，替代目录数和文件数。

## 4. 成功判据 / Success Criteria

架构重置完成的判据，而不是时间表：

1. 跟踪文件 ≤ 60,000，全量测试 ≤ 5 分钟。
2. 全仓库实质比 ≥ 50%；100 字试点档案实质比 ≥ 70%。
3. 卜辞释文记录 ≥ 1,000 条，字位链接到字 ID。
4. 100 份试点单字档案满足最低章节要求，其中 ≥ 60 份有释读史。
5. 图谱至少含 `occurs_in`、`co_occurs`、`reading_proposed` 三类带来源
   的边，能回答"某字出现次数、分期分布、高频共现字"。
6. 完成第一轮盲测并写出校准记录。

Reset completion is judged by these criteria, not by a schedule.

## 6. 抽样结果 / Sampling Result

2026-11-01 对 `corpus/` 下 3,000 个随机 Markdown 文件（共 254,169 个非空
行）按第 1 节方法分类：

| 类别 | 行数 | 比例 |
| --- | --- | --- |
| 模板行（同一行出现在 ≥ 2% 文件中） | 202,765 | 79.8% |
| 字段行 | 17,929 | 7.1% |
| 其余（可能有实质内容） | 33,475 | 13.2% |

分区：

| 语料区 | 抽样行数 | 模板 | 字段 | 其余 |
| --- | --- | --- | --- | --- |
| 001 甲骨单字 | 150,478 | 87% | 6% | 7% |
| 004 字形演化 | 83,473 | 83% | 5% | 12% |
| 003 构件候选 | 14,447 | 14% | 20% | 67% |
| 002 卜辞 | 4,796 | 7% | 26% | 67% |
| 005 馆藏实物 | 975 | 6% | 18% | 76% |

说明：模板阈值按全样本 2% 计算，003 区抽到的文件少，其模板比被低估；
"其余"一类包含被 80 字符规则折断的路径片段，所以实质比的真实值低于
13.2%。002 与 005 区的高"其余"比例对应第 1 节诊断中的真实内容。

出现次数最多的模板行依次是：`English:`、`简体中文：`、`## Boundary /
边界`、`Simplified Chinese:`、`## Concrete Questions To Check / 具体待查
问题`、`- Review status: needs_human_visual_review`，以及 EvoBC 目录中
每份文件重复四次的"This is not a ... conclusion"句。

复现命令：随机抽样 `git ls-files corpus | grep '\.md$' | shuf -n 3000`，
再对样本运行第 1 节的分类规则。实现应放入
`tools/validation/check_content_gates.py`。
