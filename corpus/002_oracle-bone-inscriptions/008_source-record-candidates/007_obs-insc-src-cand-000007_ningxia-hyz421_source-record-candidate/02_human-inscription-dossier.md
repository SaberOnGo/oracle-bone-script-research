# Human inscription dossier / 人类卜辞档案

## Source-reported object / 来源报告对象

The Commons page reports a Shang-dynasty turtle plastron from the Ningxia
Museum. It gives c. 1200 BC, dimensions of 28.3 by 20 cm, and Huayuanzhuang
East, Anyang, Henan as the place of discovery. The object reference is
`HYZ 421, H3:1325`.

Commons 页面报告这是宁夏博物馆藏商代龟腹甲，年代约为公元前 1200 年，
尺寸为 28.3 x 20 厘米，出土地为河南安阳花园庄东。对象号为
`HYZ 421, H3:1325`。

These fields are page-level source descriptions. They have not been
independently checked against a museum catalogue or excavation register.

这些字段是页面层面的来源描述，尚未与博物馆目录或发掘登记独立核对。

## Edition comparison / 版本比较

Schwartz 2019 printed page 347 contains two separately numbered entries,
`421.1` and `421.2`, with the same wording and translation but different
crack-sequence marks. The Commons page displays only one string. It is not a
complete edition transcription.

Schwartz 2019 书面第 347 页列出 `421.1`、`421.2` 两条，文字和翻译相同，
兆序标记不同。Commons 页面只显示一条字符串，不能作为完整版本释文。

The edition raw-data table confirms `HYZ 421` ↔ `H3:1325`, but gives
21.6 by 15.1 cm instead of the Commons page's 28.3 by 20 cm. The photograph
