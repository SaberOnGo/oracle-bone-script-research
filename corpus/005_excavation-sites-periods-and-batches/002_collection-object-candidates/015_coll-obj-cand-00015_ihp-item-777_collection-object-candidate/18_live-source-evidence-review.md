## Source-reported page description / 来源页面说明

The English page reports a standing dog profile and says that the dog and pig
forms are distinguished there by body thickness and tail shape. It describes
a pig-like form with mane, possibly referring to a wild pig.

英文页报告一个站立的犬侧面，并说该页以腹部粗细和尾部形状区分犬、豕形体。
它把带鬃毛的豕形描述为可能指野猪。

The Chinese page reports: `刻有一「犬」字及一圓身、長毛的「豕」形，當為習書
之作。` It further provides short source explanations beside small images.
These statements remain museum-reported descriptions; this project does not
convert them into a new reading or character assignment.

中文页报告：“刻有一「犬」字及一圓身、長毛的「豕」形，當為習書之作。”页面还在
小图旁提供简短的来源说明。这些仍是博物馆报告，本项目不把它们改写成新的释读
或单字归属。
