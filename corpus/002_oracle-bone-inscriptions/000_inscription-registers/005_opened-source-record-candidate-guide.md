# Opened Source-Record Candidate Guide / 已打开来源记录候选导览

## Purpose / 用途

This guide is the human reading entry for the eight opened inscription
source-record candidates. It is a research queue, not an accepted
inscription register and not a list of deciphered texts.
It is not a decipherment result.

本导览是八个已打开卜辞来源记录候选的人类阅读入口。它是研究队列，
不是已接受的卜辞登记表，也不是已破译文本清单。

Open the linked object README first. Then read its human dossier, source
evidence, text-quality review, linkage review, and missing-evidence plan.
Only after that should a reviewer inspect the JSON, CSV, or image route.

先打开下方对象 README，再阅读其中的人类卜辞档案、来源证据、文本质量
复核、关联复核和缺失证据计划。只有完成这些步骤后，才查看 JSON、CSV
或图像路线。

Every item below separates source-reported material from project-checked
route facts. Missing OCR, plate position, catalog identity, and character
links remain blockers unless the object dossier says otherwise.

下列每项都区分来源页面报告和项目已核对的路线事实。除非对象档案另有
说明，缺少 OCR、图版位置、著录身份和单字关联仍然是阻断项。

## Queue boundary / 队列边界

All eight folders remain source-record candidates. None is a formal `obi-*`
record, a confirmed character-inscription relation, a calibrated AI
hypothesis, or a decipherment result.

八个目录都仍是来源记录候选。没有任何一个是正式 `obi-*` 记录、已确认的
字形—卜辞关系、校准后的 AI 假说或破译结果。

The next action is to open the object named in the relevant row and resolve
its concrete blockers. Do not replace a missing item with `not_collected`;
write the exact route, access result, or source question instead.

下一步应打开相应对象并处理具体阻断项。不要用 `not_collected` 替代缺失项；
应写明具体路线、访问结果或来源问题。
