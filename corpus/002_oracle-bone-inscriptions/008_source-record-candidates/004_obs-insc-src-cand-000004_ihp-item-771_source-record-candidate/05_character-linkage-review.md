# Character linkage review / 单字关联复核

## Current status / 当前状态

No project character ID, glyph crop, component, variant, near-form, or
modern-character relation is assigned to the source proposal. The three
private photos are object views, not submitted glyph assets.

当前没有把项目单字 ID、字形裁片、构件、异体、近形或今字关系分配给来源拟译。
三张私有照片是对象视图，不是已提交的字形资产。

## Required evidence before linkage / 关联前置证据

1. Obtain the independent plate or publication locator.
2. Establish a line-addressable transcription and mark gaps.
3. Separate visible strokes from cracks, joins, and later marks.
4. Compare each proposed sign with a source-linked character dossier.
5. Record alternative segmentations and negative evidence.

1. 取得独立图版或出版物定位。
2. 建立可逐行定位的摹写并标出缺字。
3. 区分刻痕与裂纹、拼接和后加标记。
4. 将每个候选字与有来源链的单字档案比较。
5. 记录不同分段方案和反证。

Until those checks exist, `character_links` remains an empty list and the
candidate cannot enter a formal `obi-*` record.

在这些检查完成前，`character_links` 保持空列表，候选不能进入正式 `obi-*`
记录。
