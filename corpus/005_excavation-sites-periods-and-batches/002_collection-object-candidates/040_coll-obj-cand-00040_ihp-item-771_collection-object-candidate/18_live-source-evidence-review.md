## Source description and reading boundary / 来源描述与释读边界

The English page describes an example in which graphs were written with a
brush before engraving. It presents a proposed complete divination spanning
the present day to a later day, and says that a preface was engraved on the
reverse. The proposal is source-reported only; this project does not adopt it.

英文页面将其描述为先用毛笔书写、再行刻写的例子，并给出一条从当日到另一
日期的完整占问拟译，还称背面刻有前辞。本项目只记录这是来源原述，不采用该
拟译，也不把它当作已复核释文。

The captured HTML renders one personal-name character ambiguously. It is
preserved as an unresolved source-rendering issue rather than normalized.

本次 HTML 快照中的一个人名字符显示不清，现保留为来源显示问题，不擅自规范化。
