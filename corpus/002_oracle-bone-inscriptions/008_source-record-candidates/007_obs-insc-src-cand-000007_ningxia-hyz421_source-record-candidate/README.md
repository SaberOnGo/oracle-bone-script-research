# Ningxia Museum HYZ 421 source-record candidate
# 宁夏博物馆 HYZ 421 来源记录候选

## English

This folder records one photographed turtle plastron from the Ningxia
Museum. The Wikimedia Commons page identifies the object as HYZ 421,
H3:1325, from Huayuanzhuang East in Anyang. It displays one source-reported
inscription string and cites Schwartz 2019, pages 347 and 561.

The unchanged JPEG source bytes are committed under `03_visual-assets/`.
The file is licensed on Commons as CC BY-SA 3.0. That license applies to the
uploaded photograph; the museum object's own image and reuse terms remain a
separate question.

Read the human Markdown pages in numeric order before opening the JSON or
CSV. This is a source-record candidate, not a formal `obi-*` record.

## Boundary / 边界

The displayed inscription, date, findspot, object number, and literature
reference are source-reported. The visual notes are limited to directly
observable features. This project has not made an OCR, transcription,
translation, character assignment, period conclusion, or decipherment claim.

The two 12-box sentence groups are one repeated route inside the shared OBIMD
evidence family, not two independent readings. The two unknown UIDs remain
lookup metadata. Context is C4 `candidate_route`; C5 and C6 are blocked, and
C8 delivery is withheld with an abstain action.

版本记录现已确认 `HYZ 421` 对应 `H3:1325`。OBIMD 图版与照片的联合视觉
地标支持未经校准的对象身份候选，但尺寸冲突、版本来源链和馆藏号仍待解决。
两个 12 框句组只形成共享 OBIMD 祖先的重复辞例路线。两个未知 UID 仅作
检索 metadata。本项目没有制作项目摹写、翻译或单字分配，也没有提出时期
结论或破译主张。
