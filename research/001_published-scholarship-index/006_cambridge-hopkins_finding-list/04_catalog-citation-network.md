# Catalog Citation Network / 著录引用网络

## Page-Level Network / 页面级网络

The finding list places four reference systems on the same rows:

```text
Hopkins finding-list row
  -> c: Cambridge University Library number
  -> h: Chalfant 1939 reference
  -> j: Chia ku wen ho chi reference
  -> y: Ying-kuo so ts'ang chia ku chi reference
```

目录在同一行并列四套参照。这是查找路径网络，不是实物同一性证明。
星号、缺号、重复号、附注、正反面说明或缀合说明都必须回到被引著录和
图像核查，不能由代码相邻关系自动补全。

## Responsibility And Proposal Status / 责任与提出状态

- Cambridge University Library is the institutional provider of the page.
- Chalfant is named by the page for the 1939 cited catalog.
- Kuo Mo-jo is named as editor for the cited *Chia ku wen ho chi*.
- Li Hsueh-ch'in and others are named as editors for the cited *Ying-kuo*.
- The finding-list page does not identify its own compiler in the inspected
  title, introduction, table, or key.

- Cambridge University Library 是该页的机构提供方。
- Chalfant 是页面所列 1939 年著录的责任者。
- Kuo Mo-jo 被页面列为所引 *Chia ku wen ho chi* 的主编。
- Li Hsueh-ch'in 等被页面列为所引 *Ying-kuo* 的编者。
- 已检查的题名、引言、表格和代码表未说明 finding list 的具体编制者。

These are `source-reported` responsibility roles. None is, by this page
alone, a proposer of an inscription reading or a resolver of a dispute.

这些是 `source-reported` 的责任角色。仅凭此页，不能把任何人标记为某项
释读的提出者，也不能声称某项争议已经解决。

## Citation Boundary / 引用边界

A row may support a candidate cross-source link only after the editions and
object route are opened. It cannot by itself establish:

- the same physical fragment or image direction;
- a join, duplicate, re-numbering, or missing reverse;
- a complete inscription text or accepted reading;
- the scope or outcome of any scholarly disagreement.

一行最多支持“跨来源候选链接”。它不能单独确认同一实物、图像方向、
缀合、重号、缺失背面、完整释文、已接受释读或争议结论。
