- Collaborators / 合作机构: National Taiwan University and Academia

  Science.
- Main database / 主数据库: <https://xiaoxue.iis.sinica.edu.tw/>.
- Oracle-bone route / 甲骨文入口:

- Project source object / 项目来源对象:

This dossier records a database and its access boundary. It does not import
its rows, identify a character, or make a decipherment claim.

也不提出释读或破译结论。
