# Character Bucket 000001-000100 / 甲骨字分桶 000001-000100

English:
This bucket contains oracle-character object directories from
`obs-char-000001` through `obs-char-000100`.

`001_hust-obc-candidate-packet-manifest.csv` and the generated
`01_candidate-character-packet.json` files provide source-marked HUST-OBC
candidate metadata for the first 100 reserved IDs. These packets are not
accepted oracle-character records and do not make decipherment claims.

Human-readable dossiers, visual galleries, review sheets, and AI-readable
support files stay inside each concrete object directory.

简体中文:
本分桶保存从 `obs-char-000001` 到 `obs-char-000100` 的甲骨单字对象
目录。

`001_hust-obc-candidate-packet-manifest.csv` 和生成的
`01_candidate-character-packet.json` 文件，为前 100 个保留 ID 提供
带来源标记的 HUST-OBC 候选 metadata。这些 packet 不是已接受的甲骨
单字记录，也不提出释读结论。

人类可读档案、图像图廊、复核表和 AI 可读辅助文件，都保留在每个具体
对象目录内。
