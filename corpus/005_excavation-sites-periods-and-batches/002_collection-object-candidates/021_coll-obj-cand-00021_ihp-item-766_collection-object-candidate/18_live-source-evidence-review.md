## Source-reported description / 来源说明

The English page says the fragment has a character described as “bird”. It
compares two bird forms, describes one as a function word with emphasized
feathers, and describes the other as more pictographic because of its beak.
The page also lists related script examples for a rooster toponym, “to watch”,
and a swallow.

中文页说残存一“鸟”字，比较“隹”和“鸟”的鸟形，并说明其用法与鸟喙、飞羽特征；
页面还列出鸡、雈（观）和燕的相关字形。以上均是博物馆来源说明，不是本项目的新
翻译、字形归并或已确认释读。

The captured pages provide no complete line-by-line transcription. No OCR
correction, palaeographic normalization, or new reading is added here.

页面没有提供逐行完整释文。本页不增加 OCR 修订、文字学规范化或新的释读。
