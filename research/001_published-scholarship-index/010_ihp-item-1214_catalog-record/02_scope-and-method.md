# Scope and method / 范围与方法

## What the page supplies / 网页提供的内容

The current item page displays six repeated short source entries beginning
with `今夕又（有）`, image placeholders, and short lines including
`□子（巳）卜，□□亡。` and `丙辰卜，今夕亡。`.

The catalog label on the same page is `Jia Bian 0959`; it is retained as a
source string rather than normalized to a different catalog system.

当前对象页显示六条以 `今夕又（有）` 开头的短来源条目、图像占位，以及包括
`□子（巳）卜，□□亡。` 和 `丙辰卜，今夕亡。` 在内的短句。

The page also gives an English description of paired positive and negative
charges concerning possible misfortune that night. This remains
`source-reported`; it is not a project translation or new reading.

页面还用英文说明正反成对的占问及当晚是否有祸。这里保持为
`source-reported`，不是本项目翻译或新释读。

## Method boundary / 方法边界

This is a museum metadata and partial-text route. It is useful for opening
the object, comparing catalog labels, and locating future evidence. It does
not supply a complete OCR, sentence segmentation, plate layout, or reading
history.

这是博物馆 metadata 和局部文字路线，可用于开包、比较著录标签和定位后续证据，但不
提供完整 OCR、句子切分、图版布局或释读史。

The object dossier records two ignored local JPEG routes, each marked
`local_private_visual_inspection_only`. Their existence does not grant image
reuse or prove that the fragments form one historical plate.

对象档案记录两条忽略区 JPEG 路线，均标为 `local_private_visual_inspection_only`。其
存在不等于取得图像复用许可，也不证明残片构成同一历史图版。

## Applicable scope / 可适用范围

- museum label and accession cross-check;
- source-text and image-route provenance;
- a candidate link to the project object `ihp-mus-obj-00002`;
- future catalog and plate-location research.

It must not be used alone for a character assignment, inscription identity,
period refinement, or decipherment probability.

不能单独用于单字归属、卜辞身份、时期细化或释读概率判断。
