# Source Literature Scope Review / 来源文献适用范围复核

## English
This human review file keeps bibliography, database notes, source scope,
evidence level, proposer or editor, citation relations, different opinions, and
disputes visible before the source is used in any later character, inscription,
topic, or bibliography dossier.

## Bibliographic Key And Human Use / 著录键与人工使用
- Reference key / 著录键: The page defines c as Cambridge University Library, h as
  Chalfant, j as Jiaguwen Heji, and y as Yingguo suo cang jiagu ji. These keys
  route a reviewer to other catalogs; they do not prove that records are the
  same object.
- Human dossier fields / 人类档案字段: Retain the finding-list row, catalog
  references, period, group, plate or image route, collection object, findspot,
  text, and page-level evidence separately.
- Topic classification / 主题分类: The table includes topics such as ancestors,
  warfare, hunting, sacrifice, and divinatory techniques. Preserve these as the
  source's classification labels, not as a new interpretation of any
  inscription.

## Citation Relations And Limits / 引用关系与限制
- Citation routes / 引用路线: The key points to Chalfant's Hopkins catalog, Jiaguwen
  Heji, and Yingguo suo cang jiagu ji. Each cited entry needs its own edition,
  page, plate, image, and rights review.
- Unresolved notes / 未决注记: Notes such as no reverse, no CUL number, joins, and
  missing Heji values are not silently corrected. Record the source row and make
  the next catalog query explicit.
- Interpretive boundary / 释读边界: The finding list is a collection and catalog
  route. It does not supply a complete transcription, accepted reading, formal
  inscription identity, or decipherment conclusion.
- Rights and access / 权利与访问: The linked Cambridge Digital Library and 3D
  materials require separate image, IIIF, citation, and permission checks. Local
  status remains metadata_only_until_verified.

## Literature And Database Review Slots / 文献与数据库复核槽位
- Bibliography note / 书目说明: Open README.md and 10_source-evidence-dossier.md
  before citing this source in a later research note.
- Database scope / 数据库范围: Record which object type, catalog range, plate range,
  glyph range, or inscription range the source actually covers.
- Evidence level / 证据等级: Keep authority tier and source type visible; do not
  treat them as a scholarly conclusion.
- Proposer or editor / 提出者或整理者: Check source notes, database pages, paper
  metadata, or catalog front matter before assigning responsibility.
- Citation relation / 引用关系: Record whether the source cites a catalog,
  dictionary, paper, museum record, database export, or derived index.
- Different opinions / 不同意见: Absence of a disagreement row is not agreement; it
  is a pending review question until checked against bibliography notes.
- Dispute record / 争议记录: Keep disputed readings, labels, source fields, and
  mappings as pending review routes.
