# Citation network / 引用网络

## Primary database relation / 主数据库关系

- The live Xiaoxuetang portal is the primary database interface.
- The oracle-bone subroute is a more specific source route under the portal.
- The official guide explains the user-facing query and linking model.
- The official technical report is the development and system-description
  route, not a row-level scholarly edition.

- 小學堂在线门户是主数据库界面。
- 甲骨文子入口是门户下的具体来源路线。
- 官方入门页解释面向用户的检索与衔接方式。
- 官方技术报告是开发与系统说明路线，不是逐行学术释文。

## Institutional and publication links / 机构与出版关系

The Academia Sinica Center for Digital Cultures resource page routes to the
database and gives a current institutional description. Its 2017 publication
notice identifies *The Development and Application of the Xiaoxuetang
Wenzixue Database* and attributes long-term development work to Der-Ming Juang.
Those pages support provenance and development history; they do not assign a
reading to a project character.

中央研究院数字文化中心资源页链接到数据库并给出机构说明。其 2017 年
出版消息介绍《小學堂文字學資料庫的發展與應用》，并记录庄德明的长期
开发工作。这些页面支持来源与开发史，不为项目单字赋予释读。

- Resource page / 资源页:
  <https://ascdc.sinica.edu.tw/en/resources.jsp>.
- Publication notice / 出版消息:
  <https://ascdc.sinica.edu.tw/en/single_news_page.jsp?newsId=415>.
- Technical report route / 技术报告:
  <https://xiaoxue.iis.sinica.edu.tw/Content/Files/
  xiaoxue-Technical_Report.pdf>.

## Project-local relations / 项目内关系

- `src-xiaoxuetang-jiaguwen` is the project source object for the
  oracle-bone subroute.
- HUST-OBC, OBIMD, and EvoBC dossiers may use Xiaoxuetang as a future
  comparison route, but the exact row-level citation must still be opened.
- Existing character and inscription candidates therefore remain
  `candidate` or `source_record_candidate`, never `confirmed`.

- `src-xiaoxuetang-jiaguwen` 是项目登记的甲骨文子来源对象。
- HUST-OBC、OBIMD 和 EvoBC 档案可以把小學堂作为后续比较路线，但必须
  先打开具体行级引用。
- 现有单字和卜辞候选仍是 `candidate` 或 `source_record_candidate`，
  不能写成 `confirmed`。

## Unresolved citation questions / 尚未解决的引用问题

- Which exact Xiaoxuetang row cites which book, plate, or catalog?
- Which editor or proposer is attached to each disputed reading?
- Which external image or dictionary link is the source of each derivative?
- Are the current counts versioned in an export or release note?

- 哪一条小學堂记录引用了哪本书、哪一图版或哪一著录？
- 每个有争议释读对应哪位整理者或提出者？
- 每个派生资料的外部图像或字典链接来源是什么？
- 当前统计是否有带版本号的导出或发布说明？
