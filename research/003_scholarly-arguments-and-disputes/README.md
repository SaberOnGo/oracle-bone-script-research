# Scholarly Arguments And Disputes / 学术论证与争议

English:
This directory records arguments, counterarguments, disputed readings, and
evidence trails from published scholarship. It is for reviewed dispute maps,
not for new AI hypotheses or unsourced interpretation.

简体中文：
本目录记录已发表研究中的论证、反论证、争议释读和证据链。它用于已复核
争议地图，不用于新的 AI 假说或无来源解释。

## Human Review Entry Order / 人工复核入口顺序

1. Open the source object, bibliography note, or decipherment-history note.
2. Check source trail, page, plate, catalog number, and object record.
3. Identify the argument, counterargument, proposer, and disagreement.
4. Check citation relation between the sources in the dispute.
5. Check scope and evidence level before comparing claims.
6. Keep unresolved disputes as pending, not as accepted conclusions.

人工复核时，先打开来源对象、书目笔记或释读史笔记，再核对来源链、页码、
图版号、著录号和馆藏对象。随后识别论点、反论点、提出者、不同意见、
引用关系、适用范围和证据等级。

## Required Content / 必须记录内容

- bibliographic identity: author, title, venue, year, page, plate, URL,
  catalog number, database name, or object record.
- source trail: source object id, source register row, access route,
  checksum, file size, manifest, field map, derived path, and review status.
- scope: glyph, inscription, component, period, batch, collection,
  findspot, or later-script relation discussed.
- evidence level: object record, catalog, database export, peer-reviewed
  paper, monograph, web note, OCR text, or unreviewed draft.
- citation relation: cites, derives from, summarizes, disputes, rejects,
  revises, or only routes to another record.
- reading process status: reported, disputed, rejected, needs checking,
  or out of scope.
- proposer and disagreement: who proposed the claim, who disagreed, and
  where the dispute is recorded.

## Concrete Questions To Check / 具体待查问题

- Which source object and register row prove this dispute note?
- Which page, plate, URL, catalog number, or object record locates it?
- Which corpus object can this argument actually support?
- What evidence level is justified by the opened source?
- What is the citation relation between the disputing sources?
- What is the reading process status, and is it disputed?
- Who is the proposer, and where is the proposal recorded?
- Which disagreement or dispute is documented, and where?

## Boundary / 边界

A dispute note records published disagreement.
It is not a decipherment conclusion.
It is not confirmed scholarship without review, not source promotion, and
not a place to convert AI drafts into accepted claims.
