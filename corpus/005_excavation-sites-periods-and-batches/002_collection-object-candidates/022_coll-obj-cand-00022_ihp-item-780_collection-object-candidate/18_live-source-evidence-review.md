## Source-reported description / 来源说明

The English page says that three surviving scripts form part of a
meteorological divination about whether high winds would occur. It describes
one sign as “to meet, to connect,” with a road radical and a proposed fish
depiction. It describes another as a phonetic radical with a peafowl image,
used as a loan for “wind.” A related script is described as “dragon.”

英文页说三处残存文字属于关于是否有强风的气象占问。页面把一字说明为“相遇、连接”，
并提到道路构件和有学者提出的双鱼图像；另一字被说明为声符加孔雀形，借作“风”；
另有相关字形说明为“龙”。

These descriptions are museum source statements. They are not project
translations, independent palaeographic analyses, or confirmed readings.

这些说明是博物馆来源陈述，不是本项目翻译、独立文字学分析或已确认释读。
