## Source-reported description and text / 来源说明与文字

The Chinese page says this plastron contains repeated divinations about a
state named 雀 presenting elephants, horses, and monkeys. The page displays
the following eight examples; image-substituted signs remain unresolved.

中文页说该龟腹甲有多次关于雀国进呈象、马、猴的占问。页面显示以下八条例示；图片替代
的字仍是未解决显示元素。

1. `雀以象。`
2. `雀不其以象。`
3. `雀取馬。以。`
4. `雀以象。`
5. `雀不其［以象］。`
6. `雀以猱。`
7. `雀不其以猱。`
8. `以馬自[inline source glyph]（孽）。十二月。允以三丙。`

The page's English explanation says the plastron concerns other states'
tributes of elephants, horses, and monkeys. It explains 雀 as a state name
formed from small and bird, and gives short source descriptions for 象, 馬,
and 猱. These are source-reported museum explanations, not project
translations or new character conclusions.

英文说明说该龟腹甲涉及其他方国进贡象、马、猴，并解释雀由“小”和“鸟”组成、此处为方
国名，还为象、马、猱提供简短来源描述。这些是博物馆来源说明，不是本项目翻译或新的文字
学结论。

The page supplies a displayed transcription route but includes at least one

文本状态：`source_reported_transcription_with_inline_glyph_gap`。
