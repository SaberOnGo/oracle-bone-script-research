# Research Sources And Bibliography / 研究来源与书目

English:
This directory stores source records for catalogs, dictionaries, databases, papers, monographs, museums, websites, package manifests, download/access logs, and source-engineering review routes.

简体中文：
本目录保存字编、字典、数据库、论文、专著、博物馆、网站、来源包 manifest、下载/访问日志和来源工程复核路线等来源记录。

## Object-Local Source Materials / 对象内来源资料

English:
Concrete registered sources have co-located human-readable and AI-readable material bundles under `001_source-objects/`. Each source object directory keeps its README, AI packet, download/access route index, package route index, field-map route index, metadata-profile route index, and human source review sheet together. Do not create a parallel human-readable directory for sources.

简体中文：
具体已登记来源的同目录人类/AI 资料包位于 `001_source-objects/`。每个来源对象目录把 README、AI packet、下载/访问路线索引、来源包路线索引、字段映射路线索引、metadata-profile 路线索引和人工来源复核表放在一起。不要为来源另建并行的人类可读目录。

## Registers / 登记表

English:
Shared source registers remain under `000_source-registers/` so scripts can join source-level rows, download logs, package manifests, metadata profiles, and field maps. The source object directories provide the human review entrance for each concrete source.

简体中文：
共享来源登记表仍保存在 `000_source-registers/`，便于脚本关联来源级记录、下载日志、来源包 manifest、metadata profile 和字段映射。来源对象目录则提供每个具体来源的人类复核入口。

## Boundary / 边界

English:
Source records and route indexes are provenance and preprocessing infrastructure. They are not rights clearance, import approval, confirmed readings, component assignments, inscription identities, correspondence conclusions, or decipherment results.

简体中文：
来源记录和路线索引是出处追溯与预处理基础设施。它们不是权利清理结论、导入批准、已确认释读、构件归属、卜辞身份、字形对应结论或破译结果。
