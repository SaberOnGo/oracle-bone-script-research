# Source Literature Scope Review / 来源文献适用范围复核

## English
This human review file keeps bibliography, database notes, source scope,
evidence level, proposer or editor, citation relations, different opinions, and
disputes visible before the source is used in any later character, inscription,
topic, or bibliography dossier.

## Repository Research Scope / 仓库研究范围
- Repository function / 仓库功能: The Open-Oracle README describes a project hub
  that curates open datasets, benchmarks, codebases, papers, and online
  resources for AI-assisted oracle-bone research.
- Provider and maintenance / 提供方与维护: The repository is maintained by the Yuliang
  Liu research group. The current public page states last maintained 2026-07-02;
  the local README checksum remains the historical snapshot to cite.
- Evidence level / 证据等级: Scholarly project index and navigation source; it is
  not itself a primary paleographic catalog, an inscription transcription, or a
  confirmed decipherment.

## Indexed Research Relations / 索引的研究关系
- Datasets / 数据集: The README links HUST-OBC, EVOBC, OBIMD, Oracle-MNIST,
  GEVOBC/GBEDOBC, and other datasets with task and access links. Each dataset
  retains its own source object and rights review.
- Primary paper routes / 论文主路线: The index provides official routes for HUST-OBC,
  EVOBC, and the graph-based evolutionary dataset, including DOI or publisher
  links where available. These links support discovery; their claims are
  reviewed in the corresponding source objects.
- AI task categories / AI 任务分类: The README groups recognition, detection,
  retrieval, rejoining, restoration, generation, interpretation, and
  decipherment. A task label is not evidence that a model produced a scholarly
  reading.
- Human research resources / 人类研究资源: The online-resource section points to
  YinQiWenYuan, Xiaoxuetang, Guo Xue Da Shi, museum collections, and other
  databases. These routes must be opened for object, catalog, and rights

## Limits, Disputes, And Rights / 限制、争议与权利
- Index drift / 索引漂移: A project README changes as new papers, datasets, links,
  and task labels are added. Preserve the local checksum and compare the
  snapshot with the current page before citing it.
- Underlying source boundary / 下游来源边界: Open-Oracle does not transfer the rights,
  provenance, catalog identity, or scholarly status of any linked dataset. Those
  questions remain in each source object.
- Decipherment boundary / 释读边界: Words such as decipherment, interpretation,
  benchmark, and reasoning describe indexed research tasks; they do not turn an
  AI output into a confirmed academic conclusion.
- Rights / 权利: The repository welcomes contributions but does not clear every
  linked asset. Review each dataset, paper, website, image, and third-party
  material before public redistribution.

## Concrete Bibliography Checks / 具体文献核查
- Verify the local README checksum, repository revision, and current
  page maintenance date before citing an index entry.
- Follow every paper, code, data, museum, and database link and
  record the target source object rather than copying a summary.
- Compare the Open-Oracle entries for HUST-OBC, EVOBC, OBIMD, and
  GBEDOBC with their independent literature files.
- Record changed links, missing licenses, alternate labels, and
  disputed task descriptions as concrete review questions.
- 复核本地 README checksum、仓库版本和当前页面维护日期，
  再引用索引条目。
- 逐一打开论文、代码、数据、博物馆和数据库链接，将目标
  来源写入对应来源对象，不复制摘要作为结论。
- 将 Open-Oracle 中的 HUST-OBC、EVOBC、OBIMD 和 GBEDOBC
  与各自独立文献档案逐项核对。
- 把失效链接、缺失许可、替代标签和争议任务描述写成
  具体待复核问题。

## Literature And Database Review Slots / 文献与数据库复核槽位
- Bibliography note / 书目说明: Open README.md and 10_source-evidence-dossier.md
  before citing this source in a later research note.
- Database scope / 数据库范围: Record which object type, catalog range, plate range,
  glyph range, or inscription range the source actually covers.
- Evidence level / 证据等级: Keep authority tier and source type visible; do not
  treat them as a scholarly conclusion.
- Proposer or editor / 提出者或整理者: Check source notes, database pages, paper
  metadata, or catalog front matter before assigning responsibility.
- Citation relation / 引用关系: Record whether the source cites a catalog,
  dictionary, paper, museum record, database export, or derived index.
- Different opinions / 不同意见: Absence of a disagreement row is not agreement; it
  is a pending review question until checked against bibliography notes.
- Dispute record / 争议记录: Keep disputed readings, labels, source fields, and
  mappings as pending review routes.
