# Character linkage review / 单字关联复核

No character ID, component ID, variant ID, or sequence position is assigned.
The museum description is not enough to map visible marks to project character
records.

当前没有分配单字 ID、构件 ID、异体 ID 或序列位置。馆方说明不足以把图像中可
见痕迹映射到项目单字记录。

## Candidate-only routes / 仅候选路线

- Link the object to a permitted rubbing or publication plate first.
- Record each proposed occurrence with an image locator and source checksum.
- Compare any proposed character against neighboring signs and variants.
- Keep disagreement and unknown readings as separate review records.

## Blocking questions / 阻断问题

1. Which publication or catalog gives a plate and line locator?
2. Which source distinguishes inscription marks from cracks or annotations?
3. Which independently reviewed character IDs, if any, match the route?
4. Which contrary forms must be tested before any candidate is submitted?

在这些问题得到来源证据前，本候选不能进入正式单字或释读记录。
