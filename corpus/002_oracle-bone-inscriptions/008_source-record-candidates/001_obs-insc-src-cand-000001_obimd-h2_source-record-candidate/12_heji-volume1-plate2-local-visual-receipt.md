The strongest alternative is that the Internet Archive leaf is an altered,
misordered, or incorrectly attributed scan even though its printed number and
object resemble the OBIMD route. Shared image ancestry could repeat the same
catalog error.

最强替代解释是：即使印刷编号和对象近似 OBIMD 路线，Internet Archive
扫描仍可能被改动、错序或误归来源。共享图像祖先也可能重复同一著录错误。

Reopen or reject the route if an institution-bearing first-volume copy maps
printed object `2` to a different rubbing, if the local bytes fail checksum
replay, or if page-order evidence shows that `_0000.jp2` is not the first
