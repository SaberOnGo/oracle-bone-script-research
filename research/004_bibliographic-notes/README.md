# Bibliographic Notes / 书目笔记

English:
This directory stores citation notes, page references, source scope, rights
notes, and provenance trails. Full-text copies with unclear rights do not
belong here unless a reviewed policy explicitly allows them.

简体中文：
本目录保存引用笔记、页码、资料适用范围、权利说明和来源追溯链。权利
不明确的全文副本不得放入本目录，除非已有明确复核规则允许。

## Human Review Entry Order / 人工复核入口顺序

1. Open the source object and source register row.
2. Check access route, checksum, file size, manifest, and field map.
3. Record bibliography identity and source trail before interpretation.
4. Check scope, evidence level, citation relation, and rights status.
5. Check proposer, disagreement, dispute, and reading process status.
6. Write missing evidence as concrete next checks.

人工复核时，先打开来源对象和来源登记行，再核对访问路线、checksum、
文件大小、manifest 和字段映射。随后记录书目身份、来源链、适用范围、
证据等级、引用关系、权利状态、提出者、不同意见、争议和释读过程状态。

## Required Content / 必须记录内容

- bibliographic identity: author, title, venue, year, page, plate, URL,
  catalog number, database name, or object record.
- source trail: source object id, source register row, access route,
  checksum, file size, manifest, field map, derived path, and review status.
- scope: corpus area, object type, inscription, glyph, component, period,
  batch, collection, findspot, or later-script relation supported.
- evidence level: primary object record, catalog, database export,
  peer-reviewed paper, monograph, web note, OCR text, or unreviewed draft.
- citation relation: cites, derives from, summarizes, disputes, or only
  routes to another record.
- reading process status: reported, disputed, needs checking, or out of
  scope for this bibliography note.
- proposer and disagreement: who proposed the claim, who disagreed, and
  where the dispute is recorded.

## Concrete Questions To Check / 具体待查问题

- Which source object and register row prove this bibliography item?
- Which page, plate, URL, catalog number, or object record locates it?
- Which checksum, file size, manifest, or field map supports it?
- Which corpus object can this source actually support?
- What evidence level is justified by the opened source?
- What is the citation relation to another note or source record?
- What is the reading process status, and is it only reported?
- Who is the proposer, and where is the proposal recorded?
- Which disagreement or dispute is documented, and where?

## Boundary / 边界

A bibliographic note is a source trail, not confirmed scholarship by itself.
It is not a decipherment conclusion.
It is not a rights decision, corpus import approval, or draft promotion.
