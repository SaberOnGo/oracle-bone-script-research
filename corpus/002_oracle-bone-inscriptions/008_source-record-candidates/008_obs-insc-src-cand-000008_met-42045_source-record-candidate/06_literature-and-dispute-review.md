# Literature and dispute review / 文献与争议复核

## Current source routes / 当前来源路线

The Met API and object page supply museum metadata, a credit line, and image
routes. The current API record does not cite a Heji entry, plate, excavation
report, named reading proposer, or disagreement history.

大都会 API 和对象页提供博物馆 metadata、捐赠说明和图像路线。当前 API
记录没有引用合集条目、图版、发掘报告、释读提出者或分歧史。

The API period field says `Shang dynasty (ca. 1600–1046 BCE)`. This is kept as
source-reported museum metadata. It is not adopted as a project dating result.

API 的时期字段为 `Shang dynasty (ca. 1600–1046 BCE)`。本项目只把它保留为
来源报告的博物馆 metadata，不把它采用为项目断代结论。

## Concrete literature checks / 具体文献待查

- Which catalog first records accession `67.43.14`?
- Is the object reproduced in Heji or another plate corpus?
- Which scholar, if any, proposed a reading for its marks?
- Are there contrary readings, authenticity notes, or conservation reports?
- Which publication supplies findspot, batch, or archaeological context?

- 哪部著录首次记录 `67.43.14`？
- 本对象是否见于《合集》或其他图版语料？
- 哪位学者曾提出其刻痕释读？
- 是否有相反释读、真伪说明或保护记录？
- 哪篇文献提供出土地、批次或考古语境？

## Boundary / 边界

No literature claim is transferred into a project reading. Until the routes
above are independently checked, literature status is
`bibliography_and_dispute_review_pending`.

在上述路线独立核对前，不把任何文献主张转成项目释读。文献状态为
`bibliography_and_dispute_review_pending`。
