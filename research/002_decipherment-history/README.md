# Decipherment History / 释读史

English:
This directory records the history of decipherment proposals only after they
are tied to published evidence. It may record accepted, rejected, revised,
or disputed readings as source-reported history, not as new conclusions.

简体中文：
本目录记录已有文献中的释读史。只有能追溯到已发表证据时，才记录通行、
被否定、修订或有争议的释读，并且只作为来源所报告的历史。

## Human Review Entry Order / 人工复核入口顺序

1. Open the bibliography note or source object that reports the proposal.
2. Check page, plate, catalog number, inscription, glyph, and source trail.
3. Check the proposer, date, cited evidence, and later revisions.
4. Check disagreement, rejection, dispute, or uncertainty in later sources.
5. Record reading process status without creating a new interpretation.
6. Mark unresolved history as pending source review.

人工复核时，先打开报告该释读的书目笔记或来源对象，再核对页码、图版号、
著录号、卜辞、字形、来源链、提出者、提出时间、引用证据、后续修订、
不同意见、否定意见和争议。

## Required Content / 必须记录内容

- bibliographic identity: author, title, venue, year, page, plate, URL,
  catalog number, database name, or object record.
- source trail: source object id, source register row, access route,
  checksum, file size, manifest, field map, derived path, and review status.
- scope: glyph, inscription, component, period, batch, collection,
  findspot, or later-script relation affected by the proposal.
- evidence level: primary object record, catalog, paper, monograph,
  database export, OCR text, or unreviewed draft.
- citation relation: cites, derives from, summarizes, disputes, revises,
  rejects, or only routes to another record.
- reading process status: source-reported, accepted by cited source,
  rejected, disputed, needs checking, or out of scope.
- proposer and disagreement: who proposed the reading, who disagreed, and
  where the dispute is recorded.

## Concrete Questions To Check / 具体待查问题

- Which source object and register row prove this history note?
- Which page, plate, URL, catalog number, or object record locates it?
- Which glyph or inscription does the proposal actually concern?
- What evidence level is justified by the opened source?
- What is the citation relation to earlier or later proposals?
- What is the reading process status in the cited source?
- Who is the proposer, and where is the proposal recorded?
- Which disagreement or dispute is documented, and where?

## Boundary / 边界

A decipherment-history note reports published history; it does not create a
new reading. It is not a decipherment conclusion, not confirmed scholarship
without review, and not permission to promote an AI draft.
