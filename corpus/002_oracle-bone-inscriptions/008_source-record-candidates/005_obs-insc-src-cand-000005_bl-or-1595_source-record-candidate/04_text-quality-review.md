# Text quality review / 文字质量复核

## Available layers / 已有层级

1. The PNG photographs are direct visual evidence of the object surfaces.
2. The Commons pages provide short displayed strings for both sides.
3. The pages provide English glosses, but no project translation is made.
4. No OCR, line segmentation, or edition transcription was generated.

1. PNG 图像是对象表面的直接视觉证据。
2. Commons 页面提供正反面的短文字显示。
3. 页面提供英文说明，但本项目不制作项目翻译。
4. 尚未生成 OCR、逐行分段或版本摹写。

## Quality labels / 质量标签

- `image_quality`: `reviewable_source_image`; full-page PNG fetched.
- `displayed_text_quality`: `source_display_only`; page characters and
  brackets kept.
- `OCR_quality`: `not_collected`; no OCR run or checksum.
- `edition_quality`: `not_collected`; no page-level edition opened.
- `translation_quality`: `source_reported_only`; no independent translation.
- `text_quality`: `pending_independent_text_review`; identity and sequence
  remain open.

The displayed characters can contain editorial brackets or page-level
rendering choices. They must not be silently corrected, modernized, or
converted into a project reading.

页面显示的字形可能包含编辑方括号或页面层面的呈现选择。不得静默纠正、
现代化处理，也不得转换为项目释读。
