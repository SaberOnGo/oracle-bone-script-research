# Object transfer routes / 对象转移路线

## Safe transfer now / 当前可安全转移

- source identity and official URLs;
- date-stamped count observations;
- visible search-field names;
- official database-development and interface descriptions;
- access receipts and checksums for the ignored snapshots;
- a candidate comparison route with `metadata_only_until_verified`.

- 来源身份与官方 URL；
- 带日期的数量观察；
- 页面可见的检索字段名称；
- 官方数据库开发和界面说明；
- 已忽略快照的访问凭证与 checksum；
- 标记为 `metadata_only_until_verified` 的候选比较路线。

## Blocking evidence before character transfer / 转入单字前的阻断证据

Before a row can enter a character dossier, capture the exact row, image or
glyph route, source file, catalog token, and query date. Then reconcile it with
the project's object ID and record whether the row is a form, a variant, a
near-form, a component, or only a linked modern label.

单条记录进入单字档案前，必须保存确切记录、图像或字形路线、来源文件、
著录标记和查询日期。随后与项目对象 ID 对账，并记录它是字形、异体、近形、
构件，还是仅仅是链接的今字标签。

## Blocking evidence before inscription transfer / 转入卜辞前的阻断证据

Require an opened inscription image, plate or catalog locator, readable text or
an explicit no-text status, source collection, period, group, and a checksum.
The database interface alone is not an inscription identity proof.

转入卜辞档案前，必须有已打开的卜辞图像、图版或著录定位，可读文本或
明确的无文本状态，以及馆藏、时期、组类和 checksum。数据库界面本身不是
卜辞身份证明。

## AI transfer boundary / AI 转移边界

An Agent may use this dossier to choose a retrieval task or formulate a
falsifiable comparison. It may not use the portal count as a probability,
average linked labels as a translation, or promote a row to scholarship.

Agent 可以用本档案选择检索任务或提出可证伪比较，但不能把门户数量当概率，
不能把链接标签平均成译文，也不能把记录提升为学术结论。

## Concrete next checks / 具体待查问题

- Open one oracle-bone row without relying on a modern-character label.
- Save its image route and compare it with the cited catalog or plate.
- Check whether the row exposes a full inscription context or only a glyph.
- Record the exact reading history and disagreement from the cited literature.
