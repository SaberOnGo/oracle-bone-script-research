# Schwartz 2019 entry and identity conflict
# Schwartz 2019 条目与身份冲突

## Result / 结果

The permitted open-access monograph confirms that catalog number `HYZ 421`
maps to excavation number `H3:1325`. It does not confirm that the committed
Ningxia Museum photograph shows that object.

获准访问的开放获取专著确认：目录号 `HYZ 421` 对应发掘号 `H3:1325`。
但该书不能确认本目录提交的宁夏博物馆照片就是这件对象。

The raw-data table gives HYZ 421 a length of 21.6 cm and width of 15.1 cm.
The Commons photograph page gives 28.3 cm by 20.0 cm. Both pairs cannot be
the measurements of the same unchanged object. Object identity is therefore
withheld pending a plate or museum accession record.

原始数据表把 HYZ 421 的长、宽记为 21.6、15.1 厘米；Commons 照片页则记为
28.3、20.0 厘米。两组尺寸不能同时是同一件未改变对象的测量值。因此，在取得
图版或博物馆馆藏记录前，暂不确认照片对象身份。

## Commons citation audit / Commons 引用审计

The Commons citation says pages `347, 561`. Printed page 347 is a valid
locator for HYZ 421. The monograph has 477 numbered content pages and 487 PDF
pages, so printed page 561 cannot be a page in this book. The number might be
an object, plate, or source-edition locator, or it might be an error. No such
interpretation is adopted without its missing label.

Commons 引文写作第 `347、561` 页。书面第 347 页确实能定位 HYZ 421；但该书
正文编号止于 477 页，PDF 共 487 页，所以“书面第 561 页”不可能存在。该数字
可能是对象号、图版号、底本定位，也可能是录入错误。缺少标签前，不采纳任何
一种解释。

The Commons description displays one inscription string, whereas the
monograph has two separately numbered, repeated divination accounts. The
Commons string is therefore not a complete edition-level record of HYZ 421.

Commons 描述只显示一条释文，而专著列出两条分别编号、文字重复的卜问记录。
因此，Commons 字符串不是 HYZ 421 的完整版本级记录。

## Falsifiable identity hypotheses / 可证伪身份假说

### H1: Commons object identification is correct

This requires an independent museum record or source-edition plate that
matches the photograph to HYZ 421 / H3:1325 and explains the dimension
difference. Until then, H1 is unsupported.

该假说需要独立博物馆记录或底本图版把照片与 HYZ 421 / H3:1325 对上，并解释
尺寸差异。在取得证据前，H1 缺少支持。

### H2: The photograph is a different HYZ object

The dimension conflict supports checking this alternative, but dimensions
alone cannot identify which object the photograph shows. No replacement
catalog number is proposed.

尺寸冲突支持检查“照片属于另一件花东甲骨”的替代假说，但仅凭尺寸不能确认
具体对象。本项目不提出替代目录号。

### H3: One source contains a measurement error

This remains possible. It can be tested by a scale-bearing museum record,
the 2003 source-edition plate and table, or a second independent catalog.

其中一个来源存在尺寸录入错误仍有可能。可用带比例的馆藏记录、2003 年底本
图版和表格，或第二份独立目录检验。

## Decision / 裁决

- Confirm `HYZ 421` ↔ `H3:1325` at the edition-record level.
- Withhold photograph ↔ HYZ 421 identity.
- Treat the Commons string as an incomplete source display.
- Do not create formal inscription or character identities from this object.
- Next decisive evidence: museum accession record or the 2003 HYZ plate.

- 在版本记录层确认 `HYZ 421` ↔ `H3:1325`。
- 暂缓确认“照片 ↔ HYZ 421”。
- 把 Commons 字符串视为不完整的来源显示。
- 不据此建立正式卜辞或单字身份。
- 下一项决定性证据：博物馆馆藏记录或 2003 年花东图版。
