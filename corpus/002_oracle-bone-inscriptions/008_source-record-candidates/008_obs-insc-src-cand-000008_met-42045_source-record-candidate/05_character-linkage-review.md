# Character and component linkage review / 单字与构件关联复核

## Current state / 当前状态

No character, component, variant, near-form, modern-character, bronze-script,
seal-script, or evolution edge is assigned to this object. The Met API gives
no glyph IDs or text labels, and the project has not segmented the images.

本对象没有分配单字、构件、异体、近形、今字、金文、小篆或演化图边。
大都会 API 没有提供字形 ID 或文字标签，本项目也没有分割图像。

The visible vertical bands are not treated as character lines. They may
reflect inscription layout, surface wear, imaging, or an unverified mixture;
this must be checked against a plate or transcription.

可见纵向刻痕带不被当作字列。它们可能反映刻辞布局、表面磨损、成像条件或
尚未核验的混合情况，必须与图版或释文核对。

## Required evidence before linkage / 建立关联前的必要证据

- stable object and plate identity;
- a rights-permitted image or rubbing with orientation;
- line-addressable transcription or OCR;
- coordinate-bound sign segmentation;
- independent near-form and component comparisons;
- explicit positive and negative evidence for every proposed link.

- 稳定的对象和图版身份；
- 带方向且权利明确的图像或拓片；
- 可定位的释文或 OCR；
- 与坐标绑定的字形分区；
- 独立的近形和构件比较；
- 每条候选关联的正反证据。

## Boundary / 边界

The absence of a linkage row is not evidence of a reading or of scholarly
agreement. It records that character-level research has not started for this
object.

没有关联行不等于已经释读或学界一致，只表示本对象尚未开始单字层研究。
