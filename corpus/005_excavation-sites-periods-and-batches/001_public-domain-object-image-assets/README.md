# Public-domain Object Image Assets / 公共领域藏品图像资产

English:
This directory stores small, source-marked public-domain object images that
are safe to commit under the repository `SIZE_LIMIT`. Each image must have a
matching metadata file and registry rows in
`project_registry/004_asset-source-and-rights-index/`.

Images here are object-level visual evidence and provenance samples. They are
not formal paleographic readings, inscription transcriptions, or decipherment
conclusions.

简体中文：
本目录存放体积较小、来源标记清楚、符合仓库 `SIZE_LIMIT` 的公共领域
藏品图像。每张图片必须有对应 metadata 文件，并在
`project_registry/004_asset-source-and-rights-index/` 中登记来源和权利
信息。

这里的图像只是藏品级视觉证据和出处追溯样例，不是正式古文字释读、
卜辞释文或破译结论。

## Human Review Slots / 人工复核槽位

- Check image source, object record, collection, findspot, period, and batch.
- Compare any visible glyph, rubbing, component, variant, or near-form route.
- Link only to reviewed inscription, catalog, bibliography, or dispute notes.
- Record rights status, risk note, checksum, and concrete missing questions.
- 核查图像来源、对象记录、馆藏、出土地、时期和批次。
- 比较可见字形、拓片、构件、异体、近形或关系路线。
- 只链接已复核的卜辞、著录、书目或争议说明。
- 记录权利状态、风险提示、checksum 和具体待查问题。
