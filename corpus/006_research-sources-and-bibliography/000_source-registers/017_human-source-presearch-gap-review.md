# Human Source Pre-Research Gap Review
# 人类来源预研究缺口审查

Review date / 复核日期: 2026-08-01

## Purpose / 目的

This is a human reading map for the 21 registered sources. It is based on
the current source-pipeline evidence and names the next checks needed before
formal oracle-bone research.

这是 21 个已登记来源的人类阅读地图。它依据当前来源流水线证据，列出
正式甲骨文研究开始前必须完成的下一步核查。

The map does not promote a source, settle rights, assign an inscription
identity, or create a reading, component, variant, or decipherment claim.

本表不提升来源等级，不裁定权利，不确认卜辞身份，也不产生释文、构件、
异体或释读结论。

## Human Opening Order / 人类打开顺序

1. Open the source object human dossier and access-integrity review.
2. 打开来源对象的人类档案和访问完整性复核。
3. Open the download log, checksum, size, rights, and risk records.
4. 打开下载日志、checksum、大小、权利和风险记录。
5. Open the package manifest and field map, if a package exists.
6. 有来源包时，打开解包清单和字段映射。
7. Open the human-derived dossier or image route only after steps 1–3.
8. 完成前三步后，再打开人类派生档案或图像路线。
9. Record the reviewer, source citation, disagreement, and next question.
10. 记录复核者、来源引用、不同意见和下一条具体待查问题。
