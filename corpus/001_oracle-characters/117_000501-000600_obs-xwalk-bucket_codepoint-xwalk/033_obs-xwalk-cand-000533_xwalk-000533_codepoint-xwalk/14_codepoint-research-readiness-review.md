# obs-xwalk-cand-000533 Codepoint Research Readiness Review

## Purpose / 用途

This human page checks whether a codepoint crosswalk candidate has enough
opened source evidence for later formal research. It does not approve a
character identity, reading, component, or evolution correspondence.

本页只复核代码点互证候选在正式研究前还缺哪些可打开证据。它不确认甲骨字身份、释读、构件归属或字形演化关系。

## Human Reading Order / 人工阅读顺序

- Open 04_human-codepoint-crosswalk-review-sheet.md first.
- Open 06_human-codepoint-crosswalk-dossier.md next.
- Open 10_cross-source-conflict-review.md before promotion review.
- Open 12_modern-label-boundary-review.md before using labels.
- Open source registers, download logs, and field maps last.
- 先读人工复核表，再读互证档案和来源冲突复核。
- 使用现代标签或 Unicode 码位前，先读现代标签边界页。

## Readiness Slots / 就绪复核槽位

- candidate_identity_route: candidate_only; Which object-local packet and
  source row anchor this route?
- visible_glyph_evidence: needs_opened_visual_review; Which glyph image,
  rubbing, photo, or hand copy must be opened?
- inscription_plate_context: needs_source_context_review; Which inscription,
  plate, catalog, or Heji route can test it?
- cross_source_agreement: no_obimd_or_evobc_codepoint_match; Which sources
  agree only by codepoint or dataset label?
- modern_label_boundary: lookup_metadata_only; Which modern label is only a
  search clue?
- source_rights_manifest: source_marked_risk_noted; Which manifest,
  checksum, field map, rights note, and risk note apply?
- bibliography_or_proposer: needs_source_review; Which bibliography,
  proposer, or dispute route remains missing?
- formal_crosswalk_research_blockers: blocked_until_human_review; Which
  issue blocks formal codepoint crosswalk research?

## Concrete Questions Before Formal Research / 正式研究前待查问题

- Which source codepoint route needs direct human comparison?
- Which visible glyph evidence supports or conflicts with it?
- Which inscription, plate, catalog, or Heji route can test it?
- Which source rows agree only by Unicode or dataset label?
- Which modern label is only lookup metadata?
- Which bibliography, proposer, or dispute route is missing?
- Which manifest, checksum, field map, rights note, and risk note apply?
- Which issue blocks formal codepoint crosswalk research?
- 哪条来源码位路线需要人工直接比对？
- 哪条可见字形证据支持或冲突于该路线？
- 哪条卜辞、图版、著录或合集路线可用于核查？
- 哪些来源行只是共享 Unicode 或数据集标签？
- 哪个现代标签只可作为检索 metadata？
- 哪条书目、提出者或争议路线仍然缺失？
