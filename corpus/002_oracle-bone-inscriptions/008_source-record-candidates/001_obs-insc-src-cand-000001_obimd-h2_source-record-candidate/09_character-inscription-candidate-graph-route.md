# Character-Inscription Candidate Graph Route
# 字形—卜辞候选图边路线

## English

The graph file records seven dataset routes from the seven boxed source UIDs
to this H2 inscription source-record candidate. Each route preserves the
source UID, `OrderNumber`, bounding box, source-record locator, and linked
component-candidate ID. It does not say that the boxed mark is a confirmed
character or that H2 is a confirmed inscription identity.

The route file is:

`corpus/008_relationship-graph/015_character-inscription-candidate-`
`graph-edges.jsonl`

All seven edges have `dataset_candidate_not_promoted`,
`needs_human_inscription_review`, `unknown` confidence, and
`metadata_only_until_verified` rights status. The source row has no readable
full transcription or OCR. The graph therefore supports retrieval and
comparison only.

## Human Checks Before Promotion / 提升前的人类核查

- Open the private rubbing and facsimile member and record the visible sign.
- Find an independent plate, catalog, or collection object locator.
- Compare the box with the linked component dossier and record disagreement.
- Obtain a source-backed transcription or OCR and mark unreadable positions.
- Resolve the OBIMD rights conflict before making any public image derivative.

- 打开本地私有拓片和摹本成员，记录可见字形，不复制受限图像。
- 查找独立图版、著录或馆藏对象定位，并保存正反结果。
- 把字框与关联构件档案并列比较，记录差异和替代解释。
- 获取有来源的释文或 OCR，并标记不可辨位置。
- 公开任何图像派生件前，先解决 OBIMD 权利冲突。
