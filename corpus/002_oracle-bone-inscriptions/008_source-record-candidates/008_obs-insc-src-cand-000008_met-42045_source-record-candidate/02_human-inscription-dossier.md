## Direct visual observations / 直接视觉观察

The API primary image shows a long, narrow tan bone fragment on a light
background. Its upper edge is irregular and rounded; the lower end is also
uneven. The visible surface carries many fine incised marks in several
roughly vertical bands. Some marks are faint, interrupted, or obscured by
surface variation.

API 的 primaryImage 显示一块置于浅色背景上的细长棕黄色骨片。上缘不规则
且略圆，下端也不平整。可见表面有多组大致纵向排列的细刻痕，部分刻痕因
表面变化而淡化、中断或难以辨认。

The additional image shows a less densely marked surface and a red
`67.43.14` accession marking. It is not called a reverse view here because
the API supplies no orientation relation.

additionalImages[0] 显示另一面较少密集刻痕，并可见红色
`67.43.14` 馆藏号标记。本档案不把它称为反面，因为 API 没有提供方向关系。

These observations are image descriptions, not readings or sign counts.
