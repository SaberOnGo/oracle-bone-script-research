# IHP item 771 inscription source-record candidate
# 史语所 771 号卜辞来源记录候选

## English

This folder records one IHP Museum page as a candidate inscription source
record. Its project ID is `obs-insc-src-cand-000004`; the museum item is
`771`, accession `R039275+R043001`, and catalog label `I 5867+8202`.

The official page supplies an English proposed translation and says that a
preface was engraved on the reverse. Both are source-reported descriptions.
They are not a project transcription, translation, or formal reading.

Three image routes and two HTML snapshots were fetched only into ignored
`.working/ihp-771/` files. No image is committed here. Effective rights remain
`metadata_only_until_verified`.

Read the human pages in numeric order before opening the JSON or CSV. This is
not a formal `obi-*` inscription record.
