# British Library Or. 7694/1595 source-record candidate
# 大英图书馆 Or. 7694/1595 来源记录候选

## English

This folder records the recto and verso image pages for British Library
Or. 7694/1595. The project ID is `obs-insc-src-cand-000005`. The Commons
pages identify the two sides as Or. 7694/1595r and Or. 7694/1595v, and give
the object references Heji 40610r/v and Yingcang suocang jiagu ji 886r/v.

The two exact source image bytes are also kept under `03_visual-assets/` and
checked by SHA-256. The Commons pages provide public image routes and mark
the images CC0. Commons page text and catalog metadata have separate reuse
terms and are kept as source-reported evidence with attribution and risk
notes.

Read the human Markdown pages in numeric order. Open the JSON and CSV only
after the source wording, image routes, text quality, and missing checks are
clear. This is not a formal `obi-*` inscription record.

## Boundary / 边界

The Commons description, catalog references, and displayed inscription
strings are source-reported material. They are not a project transcription,
translation, astronomical conclusion, character assignment, or decipherment
result. The object identity, Heji location, reading order, text edition,
period, and scholarly disagreements remain reviewable candidate fields.

Commons 描述、著录引用和页面显示的文字都是来源报告材料，不是本项目
的摹写、翻译、天文结论、单字分配或破译结果。对象身份、合集定位、
阅读顺序、文字版本、时期和学术争议仍属于待复核候选字段。
