# Scope and fields / 范围与字段

## Database scope / 数据库范围

The official introduction describes Xiaoxuetang as an integrated database of
form, sound, and meaning. It links form, phonology, and dictionary-index
resources through a character head.

官方简介将小學堂描述为形、音、义综合数据库，通过字头连接字形、
声韵和字书索引资源。

The guide describes routes for oracle bone, bronze, Warring States, small
seal, and clerical forms, plus phonology and dictionary indexes. This is a
database scope description, not a claim that every proposed evolution is
academically accepted.

官方入门页描述甲骨文、金文、战国文字、小篆和隶书等路线，并连接
声韵及字书索引。这是数据库范围说明，不是每条演变关系都已获学界确认。

## Current count snapshot / 当前数量快照

The statistics page was retrieved on 2026-08-21.

统计页于 2026-08-21 读取。

- All glyph forms / 全部字形: 261,117.
- Phonology records / 字音: 1,341,886.
- Dictionary indexes / 索引: 366,530.
- Oracle-bone forms / 甲骨文字形: 24,701.
- Oracle-bone character heads / 甲骨文字头: 2,548.

The first three values come from the general statistics page. The last two
come from the oracle-bone database page and describe different units: a
character head is not the same as an image or a glyph row.

前面三个数字来自总收录统计页，后面两个来自甲骨文数据库页面，
其统计单位不同：字头不等于图像，也不等于字形行。

## Search fields / 检索字段

The oracle-bone interface visibly offers these search concepts:

甲骨文界面可见以下检索概念：

- character number / 字号;
- form or glyph / 字形;
- page / 页码;
- Heji number / 合集号;
- old catalog reference / 旧著录;
- category or group / 类组.

These are interface routes. A project dossier must open the returned row,
source image, catalog evidence, and context before treating a value as an
object fact.

这些是界面路线。项目档案必须打开返回行、来源图像、著录证据和上下文，
才能把某个值写成对象事实。

## Evidence boundary / 证据边界

The portal can support discovery, cross-database lookup, and candidate
comparison. It does not by itself prove an inscription identity, a findspot,
a period, a reading history, or a translation.

门户可支持发现、跨库检索和候选比较，但不能单独证明卜辞身份、出土地点、
时期、释读史或译文。
